# Vocab Tier Judge · 初中英语词汇学段判定器

> 一个跑在 Apple Silicon 上的本地词汇难度"滑动变阻器"：输入任意英文单词或短语，输出 1~5 的**期望学段读数**（1=七年级 … 3=初中毕业线 … 5=大学毕业以上），附带置信度与可解码性融合分。零 API、零生成、单次前向 35ms。

基于 Qwen3-0.6B（Apache-2.0）的 LoRA 适配器。本仓库发布**代码、适配器权重与方法论**；训练语料（课标/教材词表、教师工作语料统计）因版权不随仓库分发，README 下方给出完整的**数据配方**供自行重建。

## 快速开始

```bash
# 环境：uv + Python 3.12（Apple Silicon，MLX）
uv venv --python 3.12 ~/venvs/mlx
uv pip install --python ~/venvs/mlx/bin/python mlx-lm

# 底座（Apache-2.0，自行下载 MLX 版到任意路径）
#   ModelScope: mlx-community/Qwen3-0.6B-bf16
#   HuggingFace: mlx-community/Qwen3-0.6B-bf16

# 打分（五档旋钮）
python scripts/score_grade.py homework tyranny bother
# [1/3] homework   E=... (七年级)  ...
# [2/3] tyranny    E=... (大学+)   ...
# 批量：python scripts/score_grade.py -f 词表.txt -o 出分.tsv
```

> ⚠️ 脚本内含本机绝对路径（研究代码形态），路径常量在各脚本头部与 `PROJ`/`KF`/`MODEL` 变量处，按需替换。

## 它量什么（两个口径）

| 读数 | 口径 | 用途 |
|---|---|---|
| **E（期望学段）** | 词形本身在学段分布中的位置 | 难度排序、选词带、生词率加权 |
| **融合 E** | 若基础形在课标正册且高频出现，规则变形按可解码性下拉 | 加注判定（fined 可由 fine 解码，不必注） |

读数语义是**排序与分档**，不是精确课表；绝对档位请配合校准表使用（生成脚本 `calibration_table.py`），且**不同代际的 E 不可直接比较**。

## 方法论（判定器家族设计原则）

1. **判断不生成**：答案空间封闭在 5 个预定义 token（一二三四五），不生成、读 logits——格式幻觉在结构上不可能（等价于 Jev 的"程序拼 JSON"，更硬一档）；
2. **软标签自制校准（RLCD 的单步等价）**：多源词表（教材单元/课标/CEFR/高考3500/语料统计）的标签冲突不丢弃，转成目标分布采样训练——"报诚实概率"由正则分规则目标内生化，另配温度缩放收尾；
3. **模型管泛化，频率管已见证词**：词频等确定性数据不进 prompt（生词无频次），在分数层做融合；
4. **词表内查表、词表外问模型**：确定性优先，判定器只接清单外的长尾。

## 数据配方（自行重建训练集）

训练数据不随仓库分发，重建需要准备（均为词表/清单形态，不含语料正文）：

1. **课标词表**（2022 版三级 1600，展开后 ~1673）
2. **教材分册单元词表**（人教版七~九年级，含册/单元归属 → 年级档锚点）
3. **CEFR-J 词表**（olp-en-cefrj，CC BY-SA 4.0，词→A1..C2）
4. **高考 3500 词表**（任一版本 → 高中档锚点）
5. **自有教学语料的词频/覆盖统计**（材料类覆盖≥N 份 → 收编证据）
6. 专名清单、人名黑名单、变形归并表（脚本内已内置）

然后依次运行：`extract_vocabulary.py`（提词）→ `build_dataset_v2..v6.py`（各代配方，v6=软标签终版）→ `mlx_lm.lora`（README 顶部配方：rank8 / lr1e-4 / 3500 iters / mask-prompt / batch4）→ `eval_rheostat.py` + `calibration_table.py`。

## 训练坑备忘（踩过且写进脚本注释的）

- 判定类微调**必须 `--mask-prompt`**，否则损失被 prompt 稀释（0.34→0.037 的差距）；
- Qwen3 chat template 训练时自动插空思考块，推理读分必须复刻同前缀，否则全盘偏移；
- 适配器会把通用能力打穿（专用判定器形态）——**不要 fuse 进底座**，即插即拔使用；
- CEFR 与国内学制系统性错位（able=CEFR-B1 但国内七年级），只可作弱证据。

## 锚点层 v0.3.1（2026-09-20）

生产读数在模型 E 之上叠加两层数据性纠偏，原则：**词表为锚、模型兜底**。

1. **解码融合**（v0.2）：`融合E = min(自身E, 基础形E + 0.3)`——fined 这类罕见变形按已学基础形回落。
2. **学段户口锚**（v0.3.1，本仓只含代码）：人教教材分册/课标/genkin 分阶词表/四级书/六级书构建户口，最早学段优先——初中侧封顶 3.4（初中毕业线内），高中/四级/六级侧托底（3.6/4.0/4.3，且需模型 E≥3.0 让渡；模型强读初中而正典无记录=正典缺口，不托底留审）。

户口数据文件（`data_v6/学段户口_v2.tsv`）由词表语料生成、**不入仓**（版权）；缺失时 `anchor_layer.load()` 返回空表、锚点自动降级为纯模型读数。自建路径：`scripts/build_huji_v2.py`（数据源见脚本头注释，均为公开 GitHub 词表仓库）。

416 词边缘队列实测：骑线带（E 3.0–3.5）69 词中 44 词与词表户口冲突，全部由锚点归位；六源一致率 66%（模型 vs 最早侧），词表外长尾 34% 仍由模型独占。
